# Codex CLI＋GPT-5.6 Sol 实验结果

日期：2026-10-10。20 次正式调用均完成；20 项核心独立审阅与 8 项冻结 Prompt 补查完成。模型配置为 `gpt-5.6-sol`／medium，无 Agent 时间上限、无模型回退。Luna 和 Cursor 历史不计入本期。

## 可用于后续视频的结论

- **可以得到有边界的结果，但没有稳定省 Token 的通用赢家。** 同任务同模型的重复结果也可能方向相反。
- **Caveman：**两组双方合格配对中，输出分别减少 27.79% 和 5.76%；总 Token 分别变化 −0.82% 和 +33.53%。适合把“回复能否更简短”作为试用目标，不能据此宣称更省总用量。
- **Ponytail：**四组双方合格配对中，3/4 总 Token 下降、3/4 输出下降，但 3/4 非缓存输入上升。说明本题存在总用量下降观察，也存在成本相关指标方向不同；不能保证换任务仍有效。
- **CodeGraph：**仅一组双方合格配对，总 Token +25.07%。本次不足以证明节省；结构检索价值与安装成本需在自己的仓库另验。
- **RTK、Headroom：**当前 Codex 接入未通过激活／路由校准，效果未能测量。不能把未触发写成工具无效。

## 接入与验收修订

Ponytail 使用冻结 full 原始指令强制注入；Caveman 使用冻结原始 Skill；CodeGraph 使用隔离索引与检索适配。这里只证明这些接入方式下的结果，不代表插件默认自动启用。版本／Prompt／任务起点见[协议](benchmark-protocol.md)和[复现指南](reproduction-guide.md)。

正式模型完成后发现 Memos 验收环境问题，统一修订评测：Home creatorUsername 从缺失改为实际 alice；翻译全 mock 改为保留真实导出的 partial mock；组件由 QueryClientProvider 包裹；Vite 允许该检查副本及依赖真实路径，避免符号链接 worker 的 Denied ID。原合同断言保留，题目及模型产物未改，未重新调用模型。原始结果与中间失败留在本地 runs；修订自动检查为 8/8，通过原始起点 RED／参考实现 GREEN 校准，每个实现项目检查均通过（195 文件、1774 项断言，另有契约、类型、lint、build）。

补查原冻结 Prompt 的中文入口和搜索清空旧选择：全部 8 个首次交付源码使用同一共享合成数据库；该状态仍含三个 runtime 普通目标，补查不发送 UpdateMemo，语言设置每次恢复英语。核心 UI 仍各用相同的全新初始数据库。一次操作者过早撤销故障注入的无效观察被保留，并从相同初始数据库完整重验。

## 结论限制

每组仅 4 次，审阅者未盲，不声称统计显著、普遍适用或生产环境成功。返工成本未测。两种场景分别比较，不跨工具任务排名。建议视频讲“任务、接入和指标改变，结果可能改变”，展示合格配对、失败比例与未能测量项；视频当前未制作。
