## 环境与隔离

- 固定代码提交、工具版本、配置、模型、推理强度、Prompt、调用顺序和验收条件；启动及后续调用核对身份与证据哈希。
- 新任务采用独立副本、新会话和工作区外的私有配置目录。多阶段沿同位置的副本与会话续接，跨位置隔离。
- 新任务使用共同私有 zsh 配置，优先工作副本 `.venv/bin`。CodeGraph 新任务通过私有 CLI 提供索引查询；旧诊断续接保持原 MCP 接入。
- 不修改用户全局配置。认证副本权限 0600、私有状态目录权限 0700，结束时删除临时认证并关闭代理。
- 供应商实际解析的后端模型快照未知；仅核对请求参数及原生会话配置标签。

## 工具触发与配置边界

- Ponytail：原批次为强制 full 指令，附件搜索补测为原生插件 4.10.0 full；两种接入不能混称默认插件效果。
- Caveman：仅测试选定沟通 Skill，不覆盖同仓库其他能力。输出 Token 包括整个工作流的模型输出，不等于最后答复字数。
- RTK：固定 0.49.0，正式采用自动 Hook 改写，保存原命令、改写与执行证据；改写次数不是成功压缩次数。固定版本未覆盖 `.venv/bin/pytest` 等前缀，`git diff --no-index` 有空输出限制。
- Headroom：固定 0.39.1，正式使用 `native-offline` 命名 provider 和 ChatGPT OAuth。保留 `keep_last_turns=4` 与默认近期保护，启用 Responses 原文恢复处理；关闭 Kompress 及 fallback、响应缓存、memory、image。无近期保护的重复日志探针仅作校准。
- CodeGraph：固定 1.6.0；构建与索引维护、查询和后续阅读分别记录。检索调用成功不等于替代了阅读，也不直接证明省 Token。

区分“未能接入”“缺少作用机会”“未触发”“已处理”和“证据不足”。未触发样本保留；校准可显式检查机制，正式任务不临时催促模型使用工具。

## 独立质量验收与反馈

调用前，用原始源码确认外置合同能发现缺陷，再用参考实现确认合同可通过。参考实现不交给被测 Agent。

- 编码任务将业务源码移植到干净副本，保留原项目测试和外置合同；模型修改测试不能改变独立判卷。
- 按任务要求执行黑盒、回归、静态检查和人工浏览器复核；人工项未完成保持 pending，未盲化限制写入结果。
- 非编码诊断按固定源码核对事实、关键约束、命令与引用，不用原项目测试通过代替答案验收。
- 首次质量与最终质量分列。失败反馈沿同会话继续，保留全部轮次和成本；验收环境错误不伪装成模型失败。
- 三阶段维护只要求当前阶段及之前的行为，不提前反馈未来阶段需求。

**历史限制与后续修正**：输出工具批次的两次反馈同时包含已知上游失败，可能扩大修复范围；原成绩和成本保留，不能全部归因于工具。2026-10-12 的运行器修正只影响新批次：宽回归反馈过滤已知上游失败，仅给出新增失败摘要；摘要缺失或不完整时停止生成反馈，原始日志仍完整保存。新代码与协议需重新冻结，不续写旧身份的批次。

## 用量、耗时与停止条件

- 总 Token = 输入 Token + 输出 Token；未缓存输入 = 输入 Token − 缓存输入。缓存已经包含在输入中，不能重复相加。
- 同会话累计计数按前后差分还原每轮，并与原生记录核对。缺少前值、计数冲突或回退不能强行累加。
- 完整任务计入失败、反馈和重试；历史诊断续接保留原诊断成本及单独修复成本。
- Token 与耗时缺失保持 null，不填 0。新运行器在任一轮耗时缺失或非法时保留未知总耗时；不重写历史导出。
- 费用、订阅额度变化、真人操作及安装维护成本未直接测量时保持未知，不从 Token 或套餐价格推算。
- 额度／限流、身份漂移、调用错误和验收异常停止后续派发。不完整目录先核查，不自动覆盖、重跑或切换模型。

源码、输入与验收器变化会改变冻结身份；完成的原始记录、事故和更正投影分开保存，不能用补验覆盖原始成绩。

## 比较与结论

各工具仅与同任务、同区组 baseline 配对。公布首次通过、最终通过、反馈轮次、用量分项、每对变化和中位数；同质量比较说明纳入条件，失败与缺失仍留在全量表。四次配对是描述性小样本，不宣称统计显著或长期稳定。

局部缩减不代表整体收益；路径变化、反馈范围和远程测试波动是解释限制，不是压缩造成增耗的已证实因果。结论绑定任务、版本、接入与配置，不推广到整个产品或所有仓库。
