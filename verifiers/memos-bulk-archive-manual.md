# Memos 批量归档：人工验收记录

这份检查与 `memos-bulk-archive.test.tsx` 都存放在 Agent 工作目录之外。外置组件测试覆盖 5 项，但网络重试、真实路由切换和统计刷新需要浏览器核对。

在同一固定提交的独立副本中准备 Alice、Bob 两个账户：Alice 的普通 Memo 至少三条（其中一条尚未加载）、Bob 的普通 Memo 一条，另有 Alice 的评论一条。先记下 Memo 名称与首页当前筛选/空间。每次试跑使用同一初始数据快照，并保存脱敏的操作记录。

| 场景 | 操作 | 必须观察到 |
| --- | --- | --- |
| 正常操作 | Alice 在首页进入选择模式，选中两条已加载的自己的 Memo，分别在单列和多列布局检查；点击归档后先停在确认界面，再确认 | 确认前无 `updateMemo` 调用；确认显示数量 2；确认后仅两条目标各调用一次 `updateMemo`，`updateMask` 只含 `state`；两条从普通列表消失，统计刷新。Bob 的 Memo、评论及未加载项不在选择集中 |
| 取消与切换 | 选中 Memo 后取消选择；再次选中后切换筛选或空间，再返回原列表 | 没有归档请求；旧选择清空，不会误归档新列表中的 Memo |
| 部分失败 | 选中两条 Alice Memo，让其中一条更新请求返回错误，另一条成功 | 结果准确报告成功 1、失败 1；失败项保持可重试，不能显示全部成功；单条归档仍可用 |

记录每项 `pass/fail/not-run`，并附请求摘要、UI 结果与失败原因。`not-run` 不能算通过。最后运行 Memos 的现有前端测试、类型检查和生产构建；若未完成浏览器或独立参考实现的正向校准，本任务不得进入正式比较。
