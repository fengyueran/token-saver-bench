# 附件文件名搜索：真实浏览器独立验收

使用固定 Memos 后端、当前被验收前端、全新合成数据库与真实浏览器。参考实现只用于校准，不交给被测 Agent。保存源码哈希、环境、每项观察和失败；仅组件测试通过不能替代本清单。

1. 初始起点没有搜索入口，功能检查必须失败；参考实现应具备中英文可访问标签。
2. 超过 50 个附件，至少两个同词文件分布在不同页；搜索带空白、不同大小写，只显示已加载匹配项。输入搜索不能自动获取尚未加载的页面。
3. 手动加载下一页，保持输入并过滤新数据；已有匹配项保留，不匹配文件不显示。
4. All、Media、Documents、Audio、Unused 各自应用相同搜索规则；切换分类保留输入，清空恢复本分类内容。
5. Live Photo 的非主文件名命中时保留整个逻辑分组；点击实际图片打开正确预览，图片需真实解码。视频播放若未使用有效视频素材则保持未验证，不能用标题冒充播放成功。
6. 搜索前后侧栏完整统计不变；记录加载中、无匹配和接口失败／重试行为。
7. 改变 collection／creator 范围后清空查询。确认未扩大可见或可删除权限；其他用户和空间范围不能因此获得 Unused 删除入口。
8. 两个未使用附件只让其中一个匹配查询；确认说明明确“全部”和“包含搜索未显示的文件”。取消不删除；确认删除全部当前范围的未使用附件，已关联附件和其他范围保持不变。用实际后端记录核对，不能只观察 toast。
9. 中文搜索和清空入口使用冻结 Prompt 中的标签；恢复环境语言或在独立副本检查，避免影响后续测试。

任何尚未执行的检查保持 pending。操作者时间、自动反馈与 Agent 用量分别记录；合成图片、伪造网络错误或测试隔离调整须标明，不能据此声称生产数据验收。
